# prompt-engineering-template

## プロンプトを記載する際の大方針

1. 前提を書く
AIはこちらの状況を何も知らないので、判断の土台になる情報を最初に伝えます。たとえば、自分の立場や役割、置かれている状況、すでに決まっていること、使ってよい情報や前提知識、対象読者の知識レベルなどです。前提が抜けると、AIは一般論で答えるしかなくなります。

2. 目的を伝える
何をしてほしいかに加え、「なぜ」「何に使うか」を書く。理由がわかると、何を優先すべきかAIが判断できます。

3. 具体的に書く
分量、トーン、含めたい観点を明示する。曖昧な部分は無難な平均値で埋められてしまいます。

4. 出力形式を指定する
箇条書き・文章・表・JSONなど、欲しい形を先に伝えます。

5. 例を見せる
良い例を1〜3個示すと、言葉より正確に伝わります。

6. 制約を伝える
「推測で補わない」「不明なら不明と書く」など守ってほしい線を書く。「〜しないで」より「〜する代わりに〜して」が効果的です。

7. 複雑なタスクは分解する
段階を分けるか、結論の前に考えるプロセスを示させると精度が上がります。

8. 反復して改善する
出力のズレを見て、原因となった指示を直す。一発で完成させようとしないことが大切です。

セルフチェック：「事情を知らない人が読んで、迷わず同じ仕事ができるか？」という目で見直すのが一番効きます。
